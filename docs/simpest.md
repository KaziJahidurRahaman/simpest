# simpest package

The top-level `simpest` package re-exports the two model entry points so that
common workflows only need a single import:

```python
from simpest.models import simplace, franchestyn
```

See [simplace module](models/simplace.md) for running the crop growth model
and [franchestyn module](models/franchestyn.md) for configuring and running
the disease/fungicide simulation.

::: simpest
